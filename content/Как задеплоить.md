1. Форкаем репу Quartz: https://github.com/jackyzha0/quartz
2. В форкнутой репе жмом Code -> копируем ссылку на репу (вкладка HTTPS, там https://github.com/username/quartz.git)
3. Заходим у себя на компе в папку, где будет папка репозитория. Жмом Shift + ПКМ -> Open Git Bash here (у тебя на компе должен уже быть установлен, на ноуте скорее всего его не будет, поэтому кочай тут https://git-scm.com/downloads)
4. В терминале копируем/вставляем по очереди следующие команды, подставляя свои имя и имейл, соответственно (так вы представитесь системе Git):
	1. `git config --global user.name "John Doe"`
	2. `git config --global user.email johndoe@example.com`
5. Далее копируем/вставляем новую команду, которая будет запрашивать окошко авторизации приложения Git Credential Manager в вашем GitHub-аккаунте во время клонирования репозитория проекта:
	1. `git config --global credential.helper manager`
6. `git clone https://github.com/username/quartz.git` (тут ранее скопированная ссылка на репу с Quartz)
7. Откроется окошко авторизации приложения Git Credential Manager в вашем GitHub-аккаунте. Нажимаем Sign in with a browser, в новом, открывшемся в браузере по умолчанию окошке тыкаем на зеленую кнопку *authorize git-ecosystem*. Начнется процесс клонирования репозитория на ваш компьютер.
8. Все markdown-файлы бросай в папку **content**; потом, каждый раз как кончаешь их изменять/работать с ними, надо запушить изменения на гитхаб
	1. Shift + ПКМ -> Open Git Bash here (в папке репозитория)
	2. `git status`
	3. `git add .`
	4. `git commit -m "текст коммита"`
	5. `git push origin v4`
9. `git pull origin v4` можно использовать на всякий случай перед каждым началом работы с markdown-файлами, чтобы синхронизироваться с репозиторием на гитхабе (актуально, когда ты работаешь в этом репозитории вместе с кем-то еще, и этот кто-то еще запушил свои изменения в файлы)
10. Регаемся/логинимся на https://app.netlify.com/
11. **Add new site** -> **Import an existing project** -> **GitHub** (логинимся в гитхаб, авторизируем приложение)
12. Выбираем репозиторий quartz в списке репозиториев
13. В site name пишем, внезапно, имя сайта (идет в домен)
14. В build command пишем `npx quartz build`
15. В publish directory пишем `public`
16. Deploy quartz
17. Все изменения в markdown-файлах, сделанные на твоем компе и запушенные в репозиторий на гитхаб, будут отображаться на захощенном сайте. Congrats!
